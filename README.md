# VK-DisAgree-PAN2026
Official implementation of When Detectors Disagree --- Disagreement-Aware Ensemble for Robust AI Text Detection (PAN @ CLEF 2026). The framework combines ModernBERT, TF-IDF lexical modeling, stylometric analysis with SBERT coherence, and Binoculars-based perplexity signals within a disagreement-aware LightGBM meta-ensemble.
